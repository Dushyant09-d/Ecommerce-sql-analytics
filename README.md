# Ecommerce-sql-analytics
E-Commerce Sales &amp; Customer Analytics using MySQL | Advanced SQL, Business Insights &amp; Interactive Dashboard
📌 About the Project

This project analyzes an e-commerce business using 6 relational MySQL tables:

👥 Customers
🗂️ Categories
📦 Products
🛍️ Orders
🧾 Order Items
💳 Payments
📊 Project Structure

🎯 Key Analysis
💰 Sales & Revenue Analysis
👥 Customer Analysis
📦 Product Performance
🗂️ Category Performance
💳 Payment Analysis
📈 Revenue Trends
🏆 Top Customers & Products
💡 Business Insights

🧠 SQL Concepts
SELECT • WHERE • ORDER BY • GROUP BY • HAVING
JOINs • CASE • Aggregate Functions
Subqueries • CTEs
RANK • DENSE_RANK • ROW_NUMBER
LAG • LEAD • PARTITION BY
Window Functions • Date Analysis
